MOVA Vacuum for Homey

Control a MOVA robot vacuum (including the V70) from Homey using your MOVAhome account.

Pairing
Homey logs in with email and password only. A website login code from mova.tech will not work.
1. In the official MOVAhome app, set a password for your account (Forgot password / Set password). Do this even if you originally signed up with Apple ID.
2. Add a device and choose MOVA Vacuum.
3. Select the cloud region you used when signing up for MOVAhome (Europe, US, China, Singapore, or Russia).
4. Enter that email and password.
5. Pick your vacuum from the list of robots bound to the account.

Controls
- Start vacuuming
- Start mopping (mop only)
- Start vacuum & mop
- Pause
- Stop
- Return to dock
- Locate
- Suction (quiet / standard / strong / turbo)
- Water level (low / medium / high)
- CleanGenius (off / routine / deep)
- Empty dustbin
- Wash mop
- Battery 0–100%
- Cleaning time and cleaned area of the current job
- Status: vacuuming, mopping, vacuum & mop, returning, docked, charging, stopped
- Problem alarm when the robot reports a fault
- Consumables: remaining life of main brush, side brush, filter, mop pad, and sensors
- Dashboard widget: live floor map and robot position (Homey Pro 12.3+)

Add the Robot map widget to a Homey dashboard and select your vacuum.

This app talks to the MOVAhome cloud (*.iot.mova-tech.com). It is not affiliated with MOVA or Dreame.
